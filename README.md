# Hormiga-de-Langton-Python
Proyecto de python para simular la Hormiga dde Langton

Descarga el script i modifica COLS i ROWS par amodificar el tamaño del tablero.

Modifica dentro de la classe de Bot/Position "x" y "y" para que se situe al centro del tablero.

Utiliza la comanda `python3 -m pip install colorama` para instalar colorama.

Ejecuta el script.
